# חזרה ביסודות מדעי המחשב בשפת C#

דוגמאות קוד לשיעור חזרה לקראת בגרות ביסודות מדעי המחשב, כיתה י"א.

## 📘 [להורדת החוברת המלווה (PDF)](https://github.com/ciznerguy/ZviaReview0810/releases/download/v1/summary-ch1-ch2.pdf)

בחוברת יש הסבר, דוגמת הרצה ונקודות חשובות לכל אחת מהדוגמאות בקוד.

## מה יש כאן

| קובץ | תוכן |
|---|---|
| `Program.cs` | כל הדוגמאות, כל אחת בפעולה נפרדת עם הסבר בהערות |
| `Summary_Ch1_Ch2.html` | חוברת מלווה: הסבר, דוגמת הרצה ונקודות לשים לב לכל דוגמה |

## פרקים

| פרק | נושא | דוגמאות |
|---|---|---|
| 1 | הוראות הדפסה ומשתנים | `example1` עד `example9` |
| 2 | אופרטורים וביטויים לוגיים | `example10` עד `example20` |

## איך מריצים דוגמה

1. פותחים את הפרויקט ב-Visual Studio.
2. בקובץ `Program.cs`, בפעולה `Main`, מוצאים את השורה של הדוגמה, למשל `// example7();`
3. מוחקים את שני הלוכסנים בתחילת השורה ומריצים.
